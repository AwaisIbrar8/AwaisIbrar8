### 🚀 What I'm building now

Principal engineer at **[InsuranceMarket.ae](https://insurancemarket.ae)**, working on **myAlfred**, a super-app for insurance, payments, credit and rewards in the UAE. In the last year: **3,000+ commits across 16 repositories**, from the mobile app to the APIs, admin tools and release pipeline.

| Area | What I did | Stack |
|---|---|---|
| 📱 **Mobile app** | Lead contributor (~2,200 commits): home & engagement features, daily streaks, rewards, native credit-market forms, OTA updates, accessibility & localisation | React Native · Expo · TypeScript |
| 💳 **Payments SDK** | React Native SDK for HyperPay: Apple Pay, Google Pay, card tokenisation, 3-D Secure on iOS, published to npm | React Native · Swift/Obj-C · Kotlin |
| ⚙️ **Backend APIs** | Rewards (Gameball) integration, engagement & highlights endpoints, auth / OTP / SSO, subscriptions, quotes & payments, PII-safe logging | Node.js · Express · TypeScript · MongoDB |
| 🌐 **Web** | Customer web app: partner co-branding and embedded marketplaces (credit, holidays) | Next.js · React · Tailwind |
| 🛠️ **Admin & ops** | CRM admin for highlights and reward prize pools | Laravel · Vue |
| ✅ **Quality & delivery** | End-to-end test suites for mobile ↔ web flows, iOS signing & release automation | Playwright · Fastlane · GitHub Actions |
| 🤖 **AI tooling** | Claude Code extensions & model router, clickable app prototypes for product reviews | TypeScript · Claude |
